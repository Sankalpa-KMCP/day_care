# The Little Grove

An editorial React/Vite concept site for a future early-learning house. The experience uses candid documentary-style generated imagery, concise human copy, accessible interactions, and explicit labels wherever people, spaces, or operating details are illustrative.

## Routes

- `/` — Story-led homepage, program finder, daily rhythm, image gallery, and sample family voices
- `/about` — Founder intention, guiding principles, planned standards, and illustrative guide profiles
- `/programs` — The Nest, The Meadow, and The Canopy program concepts
- `/contact` — Opening-soon context, frontend-only inquiry demo, and FAQs

## Commands

- `npm run dev`
- `npm run build`
- `npm run lint`

The inquiry form is a frontend demonstration. It does not transmit or store data. Brand availability, licensing, location, staffing, schedules, and enrollment details are not final.
